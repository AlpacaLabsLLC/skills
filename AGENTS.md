# Repository Agent Instructions

- Read `CONTRIBUTING.md` before changing the repository or its GitHub state.
- Keep untriaged findings from feature work in the active local task register. Do not add a tracked backlog file unless the maintainer requests one.
- Never create a GitHub issue unless a maintainer explicitly asks for that public issue after triage.
- Promote work to GitHub only for a confirmed public defect, an accepted feature, or community coordination.
