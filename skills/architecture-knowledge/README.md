# /as:architecture-knowledge

read-only US architecture professional-practice terminology for Codex and Claude Code.

```text
$architecture-knowledge What is a CD set?
/as:architecture-knowledge What is the difference between Construction Documents and Contract Documents?
```

The skill reads the bundled linked Markdown corpus with no studio or project and does not create or modify workspace files. It gives a direct meaning, then material distinctions and qualifications, then clickable official sources with edition/review dates.

The corpus is orientation only. Governing project agreements and confirmed firm standards take precedence over the bundled national baseline; industry shorthand is identified as such. Unsupported claims, stale or superseded sources, and sources pending human editorial review are disclosed.

This skill does not select or interpret contracts, reproduce contract wording, copy MasterFormat tables, reproduce NCS modules, perform code/jurisdiction analysis, write outline specifications, check agreement scope, or create work plans. Use the owning workflow for those tasks.
